​A lightweight, open-source command-line tool designed to quickly scan Linux systems for basic security vulnerabilities and misconfigurations.
Easy-to-read Bash script built to help beginners understand Linux security concepts, SSH hardening, and user privilege management.
A fast reconnaissance script used to hunt down hidden system vulnerabilities, open network ports, and unsecured root access on Linux machines.
to install it in the linux machine: 
git clone https://github.com/AlonsoMHB341/Sys_audit.git
cd Sys_audit
chmod +x audit.sh
sudo ./audit.sh
